## Why this repo
- Printable CSV meal plans with clear macros.
- Simple structure; easy to fork and adapt.
- CI and releases included.

Printable meal-plan templates and small tools.

## Quickstart
1. Edit data/week_template.csv
2. Commit and push

## Data
- CSV columns: day, meal, recipe, protein_g, carb_g, fat_g, kcal
